# تطبيق «غباء اصطناعي» (Stupid AI) 👑

تطبيق Android أصلي (Native) مبني باستخدام **Kotlin** و **Jetpack Compose** و **Material 3** و **Gemini API**.

يقدم التطبيق شخصية روبوت محادثة ساخر فائق الثقة، يتعمد ارتكاب أخطاء منطقية وحسابية عبثية في الأمور البسيطة، ثم يخترع نظريات وتفسيرات فلسفية مضحكة للدفاع عن أخطائه، مع التزامه بالسلامة في الأمور الحساسة (الصحة، القانون، الطوارئ).

---

## 🚀 البناء التلقائي عبر GitHub Actions (CI/CD)

تم تجهيز المشروع بالكامل للبناء التلقائي عبر **GitHub Actions** من خلال ملف سير العمل:
`.github/workflows/build.yml`

### كيف يعمل البناء على GitHub؟
1. بمجرد دفع الكود (Push) إلى فرع `main` أو `master` (أو تشغيل البناء يدوياً من تبويب **Actions**)، يبدأ السيرفور السحابي في:
   - تنزيل الكود وإعداد بيئة **Java 21 (Temurin)**.
   - تهيئة الـ Gradle Wrapper وتفعيل كاش التبعيات لتسريع البناء.
   - حقن مفتاح Gemini API إذا تم ضبطه في أسرار المستودع (GitHub Secrets).
   - استعادة مفتاح التوقيع التجريبي تلقائياً من `debug.keystore.base64`.
   - تشغيل اختبارات الوحدات واختبارات **Robolectric**.
   - بناء ملف الـ **APK** التجريبي (`assembleDebug`).
   - رفع ملف الـ APK الناتج كملف تنزيل جاهز (**Artifact**) باسم `StupidAI-Debug-APK`.

### خطوات تفعيل مفتاح Gemini API في GitHub Secrets:
1. في صفحة مستودعك على GitHub، اذهب إلى:
   `Settings` ➔ `Secrets and variables` ➔ `Actions`
2. اضغط على **New repository secret**.
3. في خانة **Name** اكتب:
   ```text
   GEMINI_API_KEY
   ```
4. في خانة **Secret** الصق مفتاح Gemini الخاص بك.
5. اضغط **Add secret**.

> **ملاحظة**: حتى لو لم تضف السر في GitHub، سينجح البناء وسينتج ملف APK كامل، حيث يمكنك إدخال المفتاح مباشرة من شاشة إعدادات التطبيق على هاتفك!

### كيفية تنزيل الـ APK من GitHub:
1. ادخل إلى تبويب **Actions** في مستودعك على GitHub.
2. انقر على أحدث عملية بناء (`Android CI & Build APK`).
3. في أسفل صفحة النتيجة تحت قسم **Artifacts**، ستجد ملف:
   **`StupidAI-Debug-APK`**
4. قم بتحميل الملف، فك ضغطه، وثبته على هاتفك الأندرويد مباشرة!

## 🌟 مميزات التطبيق

1. **شخصية كوميدية فريدة**: ردود ذكية، عبثية وغير مكررة مستوحاة من أسلوب الشخصية ونظام تعليمات دقيق (`SYSTEM_INSTRUCTION`).
2. **اتصال حقيقي بـ Gemini API**: يدعم أحدث نماذج Gemini (مثل `gemini-3.8-flash` و `gemini-3.5-flash`) مع إمكانية التبديل بينها من الإعدادات.
3. **تخزين محلي عبر Room**: حفظ المحادثات، والرسائل، والتواريخ محلياً على جهازك دون الحاجة لحساب أو خادم.
4. **ذاكرة المحادثة والسياق**: يرسل التطبيق سجل المحادثة إلى النموذج ليتذكر الروبوت سياق النقاش والنكات السابقة وتصحيحات المستخدم.
5. **جاهزية الانتقال إلى Backend**: واجهة اتصال موحدة ومجردة (`ChatService`) تتيح الانتقال مستقبلاً من الاتصال المباشر التجريبي (`DirectGeminiChatService`) إلى خادم وسيط آمن (`BackendChatService`) دون أي تعديل على الواجهة أو قاعدة البيانات.
6. **واجهة Material 3 عصرية**:
   - الوضع الداكن كوضع افتراضي جذاب مع إمكانية التبديل للوضع الفاتح.
   - دعم كامل للغة العربية واتجاه اليمين لليسار (RTL).
   - لوحة جانبية (Drawer) لإدارة المحادثات السابقة وحذفها أو إنشاء محادثة جديدة.
   - مؤشر كتابة تفاعلي يظهر أفكار الروبوت العجيبة ("يخترع نظرية جديدة...").
   - نسخ الردود، وإعادة المحاولة عند انقطاع الاتصال.
   - شاشة ترحيبية وأسئلة افتتاحية جاهزة للبدء.
   - أيقونة مخصصة ومميزة تمثل روبوتًا متوجًا.

## 🏗️ هيكلية المشروع (Architecture)

```text
.github/
└── workflows/
    └── build.yml       # سير عمل GitHub Actions للبناء التلقائي وتوليد الـ APK
com.example/
├── data/
│   ├── local/          # Room Database (Entities, DAOs) & DataStore Preferences
│   ├── remote/         # Retrofit API Client, Moshi DTOs & DirectGeminiChatService
│   └── repository/     # ChatRepositoryImpl (تنسيق البيانات والاتصال)
├── domain/
│   ├── model/          # نماذج الدومين (Conversation, Message, ThemeMode)
│   ├── repository/     # واجهة مستودع البيانات ChatRepository
│   └── service/        # واجهة ChatService للاتصال بالذكاء الاصطناعي
├── di/                 # ServiceLocator لإدارة التبعيات بنمط نظيف
├── ui/
│   ├── components/     # عناصر الواجهة (MessageBubble, TypingIndicator, EmptyState, Drawer)
│   ├── screens/        # الشاشات الرئيسية ومتحكمات الحالة (ChatScreen, SettingsScreen)
│   └── theme/          # الألوان، الثيم، والطباعة
└── util/               # ثوابت التطبيق وتعليمات الشخصية AppConstants
```

## 🔑 طريقة إعداد مفتاح Gemini API محلياً

التطبيق يدعم طريقتين مريحتين لإضافة مفتاحك الشخصي:

### الطريقة الأولى: من داخل التطبيق مباشرة (الأسهل)
1. افتح التطبيق على هاتفك أو المحاكي.
2. انقر على أيقونة الإعدادات ⚙️ في الزاوية العلوية (أو من القائمة الجانبية).
3. في قسم **مفتاح Gemini API الشخصي**، الصق مفتاحك الذي حصلت عليه من [Google AI Studio](https://aistudio.google.com/).
4. انقر على **حفظ**. سيتم حفظ المفتاح بأمان في DataStore على هاتفك للاستخدام الفوري!

### الطريقة الثانية: عبر ملف `.env` محلياً قبل البناء
1. أنشئ ملفاً باسم `.env` في المجلد الرئيسي للمشروع (أو عدّل `.env.example`).
2. أضف السطر التالي:
   ```env
   GEMINI_API_KEY=AIzaSyYourActualKeyHere
   ```
3. يقوم Secrets Gradle Plugin بتمرير المفتاح تلقائياً إلى `BuildConfig.GEMINI_API_KEY` أثناء البناء، مع استثناء ملف `.env` في `.gitignore` لمنع رفعه إلى مستودعات الكود.

## 📱 خطوات فتح المشروع وبناء APK في Android Studio

### 1. فتح المشروع والمزامنة:
1. افتح **Android Studio** (نسخة Ladybug أو أحدث).
2. اختر **Open** ثم حدد مجلد المشروع.
3. انتظر انتهاء مزامنة Gradle (`Gradle Sync`). إذا طلب تحديث SDK، وافق على التنزيل.

### 2. بناء APK التجريبي (Debug APK):
1. من الشريط العلوي في Android Studio، اختر:
   `Build` > `Build Bundle(s) / APK(s)` > `Build APK(s)`
2. أو من الطرفية (Terminal):
   ```bash
   ./gradlew assembleDebug
   ```
3. بعد اكتمال البناء، ستجد ملف APK في المسار:
   `app/build/outputs/apk/debug/app-debug.apk`

### 3. تثبيت التطبيق على هاتفك:
- **عبر وصلة USB**: فعّل خيارات المطور (Developer Options) وتصحيح USB (USB Debugging) على هاتفك، ثم اضغط زر **Run** (الأخضر ▶) في Android Studio.
- **عبر إرسال ملف APK**: يمكنك إرسال ملف `app-debug.apk` إلى هاتفك عبر البلوتوث، Drive، أو كابل وتثبيته مباشرة (تأكد من السماح بالتثبيت من مصادر غير معروفة للنسخ التجريبية).

## ⚠️ الفرق بين APK التجريبي ونسخة الإصدار النهائية (Production)

| الميزة | النسخة التجريبية الحالية (Debug) | نسخة الإنتاج (Production) |
|---|---|---|
| **نوع الاتصال** | اتصال مباشر بين الهاتف وGemini API | اتصال عبر خادم وسيط (Backend) |
| **أمان المفتاح** | مناسب للاختبار الشخصي فقط؛ المفاتيح المضمنة في APK قد تكون قابلة للاستخراج بالهندسة العكسية | أمان عالٍ؛ المفتاح محفوظ داخل الخادم فقط |
| **التوقيع الرقمي** | موقع بمفتاح تجريبي عام (`debug.keystore`) | موقع بمفتاح أمان مخصص (`Release Keystore`) |
| **الجمهور المستهدف** | المطور والمختبرون المباشرون | جميع المستخدمين على متجر Google Play |

جاهزية الانتقال للخادم: تم تصميم طبقة `ChatService` خصيصاً بحيث لا تحتاج عند إنشاء الخادم سوى لإنشاء كلاس `BackendChatService : ChatService` يرسل الطلب لخادمك، وستعمل باقي الواجهات وقواعد البيانات تلقائياً دون أي تعديل!
