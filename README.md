# تطبيق «غباء اصطناعي» (Stupid AI) 👑

تطبيق Android أصلي (Native) مبني باستخدام **Kotlin** و **Jetpack Compose** و **Material 3** مع دعم كامل لمحركات **Google Gemini** و **xAI Grok**.

يقدم التطبيق شخصية روبوت محادثة ساخر فائق الثقة، يتعمد ارتكاب أخطاء منطقية وحسابية عبثية في الأمور البسيطة، ثم يخترع نظريات وتفسيرات فلسفية مضحكة للدفاع عن أخطائه، مع التزامه بالسلامة في الأمور الحساسة (الصحة، القانون، الطوارئ).

---

## 🌟 مميزات التطبيق

1. **شخصية كوميدية فائقة الحيوية**:
   - تم صياغة وتطوير نظام التعليمات (`SYSTEM_INSTRUCTION`) ليكون مليئاً بالمرح والذكاء والسرعة، ويمنع تماماً الإجابات الجافة أو الروتينية.
   - ردود ساخرة متجددة، دفاع مستميت عن الأخطاء بنظريات عجيبة (مثل "التجاور العددي" و"تآمر الأرقام").
2. **دعم كامل لمحركات Google Gemini و xAI Grok**:
   - التبديل الفوري بين محركي **Gemini** و **Grok** بنقرة زر واحدة من الإعدادات.
   - **نماذج Gemini المدعومة**:
     - `gemini-3.8-flash` (الافتراضي فائق السرعة)
     - `gemini-3.5-flash`
     - `gemini-3.1-pro-preview`
     - `gemini-3.1-flash-lite-preview`
     - `gemini-2.5-flash-image`
   - **نماذج Grok المدعومة**:
     - `grok-2-latest` (الافتراضي الذكي والساخر)
     - `grok-2-1212`
     - `grok-2-vision-1212`
     - `grok-beta`
     - `grok-vision-beta`
3. **تخزين محلي كامل عبر Room**:
   - حفظ المحادثات، والرسائل، والتواريخ محلياً على جهازك دون الحاجة لحساب خارجي.
4. **سياق المحادثة والذاكرة**:
   - إرسال السجل الكامل للنقاش للمحرك النشط ليتذكر الروبوت النكات وتصحيحات المستخدم واسمه.
5. **إدارة مرنة للمفاتيح**:
   - إدخال مفتاح Gemini ومفتاح Grok بشكل مستقل وحفظهما محلياً في DataStore.
6. **واجهة عصرية بتصميم Material 3**:
   - الوضع الداكن الافتراضي الأنيق مع خيار الوضع الفاتح أو التلقائي.
   - دعم كامل للغة العربية واتجاه RTL.
   - لوحة جانبية (Drawer) لإدارة المحادثات السابقة وحذفها أو إنشاء محادثة جديدة.
   - مؤشر كتابة تفاعلي بأفكار الروبوت العجيبة ("يخترع نظرية جديدة...").
   - شاشة ترحيبية وأسئلة افتتاحية سريعة.

## 🔑 طريقة إعداد المفاتيح (Gemini و Grok)

### من داخل شاشة إعدادات التطبيق ⚙️:
1. افتح شاشة **الإعدادات** في التطبيق.
2. اختر المزود النشط: **⚡ Gemini** أو **🚀 Grok**.
3. اختر النموذج المفضل لديك من القائمة المنسدلة.
4. الصق مفتاحك:
   - **لمفتاح Gemini**: احصل عليه من [Google AI Studio](https://aistudio.google.com/) ثم اضغط "حفظ مفتاح Gemini".
   - **لمفتاح Grok**: احصل عليه من [xAI Console](https://console.x.ai/) (يبدأ بـ `xai-...`) ثم اضغط "حفظ مفتاح Grok".
5. ابدأ المحادثة فوراً واستمتع بالذكاء الساخر!

## 🚀 البناء التلقائي عبر GitHub Actions (CI/CD)

تم تجهيز المشروع بالكامل للبناء التلقائي عبر **GitHub Actions** من خلال ملف:
`.github/workflows/build.yml`

### كيف يعمل البناء على GitHub؟
1. بمجرد دفع الكود (Push) إلى فرع `main` أو تشغيله يدوياً من تبويب **Actions**:
   - يتم إعداد بيئة **Java 21 (Temurin)**.
   - يتم تفعيل الـ Gradle Wrapper مع كاش التبعيات.
   - يتم حقن المفاتيح من أسرار المستودع (GitHub Secrets) إن وجدت.
   - تشغيل اختبارات الوحدات واختبارات **Robolectric**.
   - بناء ملف الـ **APK** التجريبي (`assembleDebug`).
   - رفع ملف الـ APK الجاهز للتثبيت كملف **Artifact** باسم `StupidAI-Debug-APK`.

---

## 📱 فتح المشروع وبناؤه في Android Studio

1. افتح **Android Studio** (نسخة Ladybug أو أحدث) واختر مجلد المشروع.
2. انتظر اكتمال مزامنة Gradle (`Gradle Sync`).
3. لبناء الـ APK من الطرفية:
   ```bash
   ./gradlew assembleDebug
   ```
4. ملف الـ APK الناتج ستجده في:
   `app/build/outputs/apk/debug/app-debug.apk`
